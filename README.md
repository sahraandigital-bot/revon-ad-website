# REVON.AD — Cinematic 3D Agency Website

A responsive React + Vite landing page with a Three.js interactive 3D hero and GSAP scroll reveals.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown in the terminal.

## Before publishing
- In `src/main.jsx`, replace the sample WhatsApp number `919876543210` with your real WhatsApp number (country code + number, digits only).
- Replace Instagram and LinkedIn placeholder URLs in the footer with your real profile links.
- Replace the three sample project cards with real client work when available.

## Deploy with GitHub + Vercel
1. Create a GitHub repository named `revon-ad-website`.
2. Upload the contents of this folder (not the outer zip file).
3. In Vercel, choose **Add New → Project**, import the repository.
4. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
5. Click Deploy. Future pushes to the connected GitHub branch trigger deployments.
